    Edit a month — planned & actual

    Copy actions copy recurring planned income/expenses only — one-offs are never copied. Changes save automatically. In the Actual view, expense fields for a month with daily-log entries come from the daily log rollup (see Daily expenses) and are shown read-only there.

    Daily expenses

    To review

    New money to or from people. Transfers between your own accounts, card bills and paychecks are sorted out automatically.

    How daily expenses work

    Add what you actually spent, each day. The category fills in automatically (Gemini when a key is set, otherwise keyword rules) and you can always override it. Each month's daily total rolls up into that month's actual expenses. Sharing an expense (roommate, friends)? Fill in My share with just your portion — actuals count only that; the split itself lives in Splitwise.

    Pending charges

    Still settling at the bank, so not counted yet. Tap Count it now on any you know won't change; when it posts, that expense updates to the final amount instead of being added again.

    Credit cards — statement cycles

    A credit card bill is due in a later month — and often a different paycheck — than the spending itself. Add each card with its statement start and end dates: expenses you tag with that card on the Daily expenses tab and that fall inside the statement window group here, and their total is the estimated statement balance for that cycle.

    Bank accounts

    Settings

    Gemini auto-categorization

    Checking…

    Two ways to configure the key: paste it here (stored only in the database, used only by the categorize function, and never displayed again — you'll see just its last 4 characters), or set the GEMINI_API_KEY secret on the Cloudflare Pages project, which takes precedence. Without any key, categories fall back to keyword rules. Never commit a key to git — see the README for how to get one and how to restrict it.

    Splitwise — live balances

    Checking…

    Get the key from Splitwise: sign in at splitwise.com → your account → Privacy and Security → Your Apps → register an app (any name) → generate a personal API key on its page. The key is stored only in the database and used only by the server to read your balances — the Splitwise tab is read-only and nothing is ever written back to Splitwise. Or set the SPLITWISE_API_KEY secret on the Cloudflare Pages project, which takes precedence.

    Merchant rules

    Expenses from these merchants always go under the category you chose, before Gemini or the keyword rules are asked.

      Security — access code & devices

      Your budget is protected by an access code. Each device that signs in gets its own session (90 days, renewed as you use it) — revoke any device here and it is signed out immediately. Changing the code signs out every other device.

      Automation (Plaid sync)

      To connect the automatic expense sync, open a pairing window and give the one-time code to the sync script. The code works once and expires in 10 minutes. A paired script can only add and list expenses and update card statement dates — it can't read your plan, change settings, or manage devices — and it stays paired for 180 days.
